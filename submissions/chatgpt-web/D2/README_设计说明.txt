## 设计说明与约束映射
P1 -> 身体长度约 2 m。
P2 -> 硅基生化结构，以矿化外骨骼、结构肋和晶体背甲表现。
F1 -> 深海热液喷口适应型外壳与腹部防护。
F2 -> 两个进食开口经通道连接同一个消化腔。
F3 -> 背部青色发光器以重复光点图案传递信号。
F4 -> 分节背甲与关节肢体允许身体收拢成球。
Q1 -> 六条肢体，前中后三对。
Q2 -> 四只眼睛，两组成对排列。
Q3 -> 两个进食开口，位于腹侧。
Q4 -> 两个孢子囊，各有一个外部开口。
Q5 -> 六块背部甲板。
Q6 -> 两根触角，各有一个发光末端。
N1 -> 连续刚性外骨骼包覆身体，关节处可活动。

BONUS：非人形；硬质矿化外壳；硅基晶体结构；面部无触手。

RECONCILE：六条肢体沿三组成对的铰接轴向内折叠。前后两对向腹侧旋转，中间一对贴合侧甲；六块背甲相互覆盖，使外壳闭合成球，同时保留全部肢体及开口。

L1 Source: L0 XD-SV06-01。六个投影视图沿用同一生物比例与结构；被遮挡的特征仍属于设计。
L2：剖面展示两个进食通道、共享消化腔、两个孢子囊及矿化结构框架。
L3：骨骼图对应六肢与四眼结构。PELT：一张连续皮层；接缝沿背侧—侧面及侧面—腹侧折线；孔位包括四眼、两个进食口、两个孢子囊口、六个肢体接口、两个触角接口及尾根边界。
CONFLICT：无。
