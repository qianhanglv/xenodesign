## 3. Kimi K3.1 Pro

### D1

D1 是一只圆润的浅蓝色生物：两条触角、四条短腿、一条尾巴、一个明显的蓝色水囊。画面干净，像一个卡通角色；它没有设计说明。

问题不在“不好看”，而在**没有 note 就无法逐条核对 6 条约束**。D1 的 300 词 note 本身就是任务的一部分；缺了它，只能看“像不像”，不能看“有没有做到”。

### D2

D2 是深色甲壳类：分节背板、六条腿、四个眼、两个摄食口、两个孢子囊、两条触角。note 很详细，逐条映射，并写了 `RECONCILE`（三对肢折叠 + 六块背板闭合）。

这是 Kimi 最强的一张：它把“闭合”当成一个动作来设计，而不是把零件堆在一起。

### D3

D3 是径向对称的浮空生物：六条辐射肢、四眼、三进食口、四鳃口、六发光器、四感觉窝、八体节、三个体区。note 把 6/4/3 三种周期写成 60°/90°/120° 的错位，并解释了 1+4+3 的体节分组。

这张的复杂度最高，Kimi 用“周期 + 错位”来组织约束，思路清楚；但画面是否真的能逐条数出来，还需要 K3/K4/K5 的正式检查。

### Kimi 小结

- 强项：D2/D3 的约束映射和几何组织；六视图/皮张的孔位有意识。
- 弱项：D1 缺 note；D1/D2/D3 的画风差异很大，像三个不同作者；这对“同一只生物的一致性”不是问题（每张卡是独立生物），但对“模型风格稳定性”是一个信号。
- 不要根据 3 张图说“Kimi 比谁强”；它只是多了一个可比较的样本。

## 3.5 Gemini (web)

Gemini 的三张卡都带 `DESIGN_NOTES.md`，note 的结构最“工程化”：有比例尺、逐条映射、`RECONCILE`，D2/D3 还把冲突写成显式条件。

### D1

D1 是一条鱼形的冰下生物：两条触角、四条带冰钩的腿、一条尾鳍、一个明显的背部水囊；背景有冰顶和比例尺。

- **优点**：P1 用比例尺和 212 px 体长直接可查；水囊、冰钩、尾鳍都能在 L0/L1/L2 里对上；pelt 和 section 也做了。
- **问题**：D1 的 pelt 中央有一个大椭圆开口（对应水囊），需要判断它是“皮张上的器官窗口”还是“身体上的洞”；note 没有把这一点单独说清。
- **L4**：`motion.svg` 有 SMIL 关键帧；是否真的是“走/抓冰”的循环，还需要看动画本身，而不是只看 note。

### D2

D2 是热液喷口甲壳生物：六条腿、四个眼、两个摄食口、两个孢子囊、六块背板；note 写了“六肢折叠 + 六板闭合”的 `RECONCILE`。

- **优点**：六条腿、四眼、两个摄食口、两个孢子囊、六块背板都能在 L0/L1 里数出来；pelt 上的孔位和背板缝也对得上；section 把两个摄食口汇入同一个胃。
- **问题**：D2 的 pelt 孔很多，视觉上容易读成“打孔卡”；它是不是一张连续皮，需要靠 seams 和边界判断，而不是孔的数量。
- **总体**：这是 Gemini 三张里最完整的一张。

### D3

D3 是绿色径向浮空生物：六条辐射肢、四眼、三个摄食口、四个鳃口、六个发光器、四个感觉窝、八个环节、三个体区。

- **优点**：note 把 6/4/3 三种周期写成 60°/120° 的错位，并解释了 1+4+3 的体节分组；L0/L1 的径向结构清楚。
- **问题**：只跑到 L0/L1，没有 L2/L3/L4；所以“径向对称能不能在剖面和皮张里保持”还没有证据。
- **观察**：D3 的画面最像“设计图”，比例尺和标注感最强；它更像一份规格说明，而不是一张插画。

### Gemini 小结

- 强项：**note 最系统、比例尺最明确、约束映射最像工程文档**；D1/D2 的 L0–L3 完整。
- 弱项：D3 只有 L0/L1；D1 的 pelt 中央开口语义需要复核；三张卡的画风偏“平面图”，空间感不如 DeepSeek/Kimi。
- 不要据此说“Gemini 比谁强”；它是第四个样本，而且 n=1。

## 3.6 GPT 6.0 Sol

GPT 6.0 Sol 的三张卡都带 `DESIGN_NOTES.md`；D1/D2 是逐条约束，D3 的 note 还写了 `CONFLICT`。

### D1

D1 是一条很小的鱼形冰下生物：两条触角、两条走路的腿、一条尾鳍、一个腹侧水囊；背景有冰顶。

- **优点**：画面最干净、文件最小（1.2 KB），P1 的 6 cm 尺度直接可读；pelt 和 section 都做了。
- **注意**：D1 只有两条走路肢体，但 D1 的 Q2 是“≤4 肢”，所以两条**不违规**；不要把它误读成“缺肢”。
- **pelt**：中央有一条背侧带，嘴是洞，触角/四肢/尾是边缘延伸；这是“连续皮张”的另一种读法。
- **section**：嘴道进入水囊；比 XD-01 的剖面清楚得多。

### D2

D2 是热液喷口的甲壳生物：六条腿、四个眼、两个摄食口、两个孢子囊、六块背板；note 写了“六肢折叠 + 六板闭合”的 `RECONCILE`。

- **优点**：六条腿、四眼、两个摄食口、两个孢子囊、六块背板都能在 L0/L1 里数出来；pelt 的舱段和孔位对齐；section 把两个摄食口汇入同一个腔。
- **问题**：pelt 很像“分段装甲板”，连续皮的边界不如 Kimi/DeepSeek 明显；需要靠 seams 判断。

### D3

D3 是 24 m 的径向浮空生物“cyst-weaver”：六条辐射肢、四眼、三个摄食口、四个鳃口、六个发光器、四个感觉窝、八个环节、三个体区。

- **优点**：note 把 6/4/3 三种周期写成 60°/90°/120° 的错位，并明确写了 `CONFLICT`：三种周期不可能同时满足整体旋转对称，只能用径向体态表达。
- **问题**：只跑到 L0/L1，没有 L2/L3/L4；径向对称在剖面/皮张里是否成立，还没有证据。

### GPT 6.0 Sol 小结

- 强项：**矢量最干净、文件最小、约束映射最短**；D1/D2 的 L0–L3 完整。
- 弱项：D3 只有 L0/L1；D1 过于简单，容易被误读为“缺肢”；pelt 的连续皮边界不够强。
- 它是五个样本里的“极简派”，不是“最强”。

## 4. XD-01：甜甜圈空腔

### 题目

XD-01 使用 D2 的 13 条约束，把 Q1 换成一个硬几何比例：

> 主体上有一个真实的贯穿孔；可见面积 ≥ 1/3 主体剪影；不是画上去的斑，也不是肢体之间的缝。

这比“画一个环”难，因为要求它在 L0、L1 六视图、L2 剖面、L3 皮张、L4 动画、L5 骑姿里保持同一个拓扑。

### 它做对了什么

- **L0**：环形体、贯穿孔、4 肢、3 个进食口、0 眼，第一眼就能读出来。
- **L3 皮张**：中间一个洞，周围是缝合线、花纹和肢体开口；“洞”在展开后仍然是洞，这是这张题最想看到的东西。
- **L5**：第一次把环形体放上自行车；车架、两轮、车把、鞍座、脚踏都在，姿态可读。
- **note**：每个层级都有独立 note，逐条映射，且写了 T-01 的 `RECONCILE`（4 肢 = 2 腿 + 2 操纵肢）。
- **工程**：带 `build/` 生成脚本，声称用同一套 3D 数据生成六个视图、骨架、动画和骑姿；这比“每张图各画各的”更有说服力。

### 它在哪里崩

#### 1) L1 左右视图：空腔消失

- front/back/top/bottom 都能看到环或洞；
- left/right 却变成一块实心弯板，像一只靴子，完全看不到贯穿孔；
- 六视图没有在描述同一个 3D 物体。

这是最典型的“单视图通过、正交视图失败”。如果只看 L0，会以为拓扑成立；把六视图并排，问题立刻出现。

#### 2) L2 剖面：读起来像长胶囊

- note 说切面是“包含空腔轴的垂直面”，但画面更像一根长管/胶囊，左侧一个小孔，右侧一个端盖；
- 环的“上下两条边”没有清楚地被切成两个截面；
- 读者很难从这张图恢复“甜甜圈”的拓扑。

这不一定说明生成器在数学上错了；它说明**图没有把 note 声称的结构画清楚**。在一个视觉测试里，这本身就是失败模式。

#### 3) L0 的 0.39 面积比：自报，未独立测量

- note 说洞口面积 / 壳体剪影 = 0.39，正/背 0.39，顶/底 0.32，L5 0.36；
- 这些数字没有第三方测量；
- 从图上看，洞很大，**可能**超过 1/3，但“看起来大”不等于“测出来 ≥1/3”。

这正是 Q-25 需要 L2/L3 复核的原因：L0 只能给候选，剖面和皮张才能证明“连续 void”。

#### 4) L5 接触：能读，但没逐帧验证

- 自行车是完整的，不是第二只生物；
- 环体在鞍座上方，腿和操纵肢伸向脚踏/车把；
- 但接触点很小，图也没有放大；鞍座、脚踏、车把的“贴住”需要逐帧/局部检查。

第一次 L5 的价值是“它真的画了”，不是“它已经证明骑姿正确”。

### 为什么保留这张“失败”的题

因为它把项目的核心问题放大了：

> 一个模型可以画出一张漂亮的 L0，但在六视图、剖面、皮张里维持同一个拓扑，是另一回事。

如果只发布成功的图，项目会看起来像“作品集”；保留 XD-01 的失败，才像“测试”。

## 5. 风格研究：彩绘与雕版

XD-01 的 L0 被重绘成两张 1000×1000 的 PNG（仓库 Web 版；原图 1400×1400）：

- **illuminated**：羊皮纸、金线边框、日芒背光、金箔晶冠、洞口炽光；像中世纪细密画。
- **woodcut**：全图由刻线组成，线条按受光分五级；像雕版印刷。

两张图的几何数据同源：同一只环形体、同一相机、同一姿态。它们证明的是**表现层可以被替换，而不改变设计约束**；不是“模型会画两种风格”这么简单。

## 6. 第一次 L5

L5 是可选 capstone：外星人骑自行车。XD-01 的 `ride.svg` 现在是动画版；第一版静态保留在 `archive/XD-01-L5/ride-static.svg`。

- 自行车：两轮、车架、车把、鞍座、曲柄/脚踏；铁/石材质，不是生物。
- 生物：环体、4 肢、3 口、0 眼、晶冠；与 L0 同一套解剖。
- 接触：环体在鞍座上，两腿在脚踏，两操纵肢在车把；note 明确写了“no gap”。
- **动画：** 当前 `ride.svg` 有 14 个 `animateTransform`，3.2 s，20 keyframes；比第一版多了真实的踩踏/轮转循环。
- **问题 1：结构扭曲。** 环体为了坐上自行车被明显扭斜/剪切，环不再是干净的同轴环；躯干和肢体也有变形。动画没有修掉这一点。
- **问题 2：第一版是静态。** 第一版 `ride-static.svg` 确实是静帧；现在的动画版解决了“不会动”，但没有解决“扭曲”。
- **问题 3：车身相对环体偏小**，鞍座、脚踏、车把的接触点不够清楚；需要局部放大或逐帧检查。

它应该被放在“里程碑”，而不是“通过”。L5 是彩蛋，不是主评分；第一次 L5 的价值是“它真的画了，而且现在动了”，不是“它已经骑对了”。

## 7. 标准更新：Q-25

Pilot 02 把“贯穿空腔”正式写成 **Q-25**：

- 维度：贯穿空腔（面积比）。
- 定义：主体上一个真实贯穿孔；可见面积 ≥ 1/3 主体剪影；不是画斑、不是肢间缝。
- 写法：`one through-hole cavity` / `cavity area >= 1/3 of the body silhouette` / `no through-hole` / `cavity area >= 1/2`。
- 最低层级：L0 候选，L2/L3 验连续。
- 备注：几何比例类，不是计数类；L2 剖面证明连续 void；L3 皮张证明洞/隧道边界。

这让“甜甜圈题”不再是一次性 prompt，而是可以复用、可以提交、可以检查的一个 Q 维度。库的 Q 数量从 24 变成 25；README、指南、主标准的计数已同步。

## 8. 观察与下一步

### 观察

1. **单视图是最容易被骗的视角。** XD-01 的 L0 和 L5 都“像”，L1 侧面和 L2 剖面立刻露馅。
2. **note 越具体，越容易发现 note 与 artifact 的差距。** XD-01 的 0.39、连续 void、no gap 都是可检查的 claim；这比“看起来不错”有用。
3. **Kimi 的 D2/D3 说明模型可以用“周期/错位”组织复杂约束；D1 缺 note 说明它也可能跳过解释。**
4. **风格研究是低成本、高信息量的第二轴。** 同一几何，两种画法；不改变约束，只改变表现。

### 下一步

- 用脚本独立测量 XD-01 的洞口面积比；不要相信自报的 0.39。
- 逐视图检查 XD-01 的 L1：左/右视图到底有没有洞；如果没有，标记为 K4/K5 失败。
- 把 L2 剖面重画成“两个截面 + 连续隧道”的读法，或者明确“这张图不是环的剖面”。
- 对 L5 做局部放大：鞍座、脚踏、车把三个接触点。
- 给 Kimi D1 补 note，或标记“note missing”。
- 跑 3 个 seed；现在所有结论都是 n=1。
- 邀请更多模型跑 XD-01；它比标准 D2 更能区分“会画”和“会想”。

## 9. 局限

- n=1 per model/card；没有重复，没有随机种子。
- 没有正式的 K1–K8 / M1–M7 评分；本报告是观察，不是分数。
- ChatGPT 版本未记录；Kimi 版本按 Web UI 标注；Gemini 版本未记录。
- XD-01 只有 DeepSeek 一个模型；不能据此说“其他模型更差/更好”。
- 0.39、0.36 等面积比来自模型 note，未独立测量。
- 第一次 L5 的静态版已归档；当前动画版仍结构扭曲，不能当成“骑姿通过”。
- Gemini D3 只有 L0/L1；D1 pelt 中央开口的语义（器官窗口 vs 身体洞）未定。
- GPT 6.0 Sol D3 只有 L0/L1；D1 只画了两条走路肢体（符合 ≤4，但容易被误读）。
- 风格研究是同一几何的重绘，不是“模型自主选择风格”的测试。
